# Operational Risk Modeling in R

Academic project focused on operational risk modeling using the Loss Distribution Approach.

## Project goal

The goal of the project was to estimate operational risk measures based on historical operational loss data. The analysis included fitting frequency and severity distributions, running Monte Carlo simulations, and estimating OpVaR and OpES.

## Scope of the analysis

- data preparation and exploratory analysis,
- analysis of annual loss frequency,
- analysis of loss severity,
- fitting probability distributions to frequency and severity data,
- goodness-of-fit assessment,
- Monte Carlo simulation of annual aggregate losses,
- estimation of OpVaR and OpES.

## Methods

- Loss Distribution Approach,
- frequency-severity modeling,
- Monte Carlo simulation,
- Operational Value at Risk,
- Operational Expected Shortfall,
- goodness-of-fit tests.
